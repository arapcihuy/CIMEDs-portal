# CIMEDs Portal (Central Integrated Medical Data System)

**Sistem Informasi Medis** yang dirancang untuk integrasi data kesehatan yang efisien dan terpusat. Proyek ini merupakan inisiatif kolaborasi dengan **Universitas Gadjah Mada (UGM)**.

> [!NOTE]
> Repository ini berisi **Prototype / Konsep Awal** yang dibangun menggunakan teknologi TypeScript & React modern untuk mendemonstrasikan fungsionalitas dan alur sistem.
>
> **Status Pengembangan:** Versi produksi direncanakan akan dimigrasikan dan diimplementasikan menggunakan platform **WordPress** untuk kemudahan pengelolaan dan skalabilitas di fasilitas kesehatan target.

## ⚕️ Tentang CIMEDs

CIMEDs bertujuan untuk menjadi solusi manajemen data medis yang:
- Terintegrasi antar unit layanan
- Aman dan reliable
- User-friendly untuk tenaga medis
- Efisien dalam pengolahan data pasien

## 🛠️ Tech Stack (Prototype)

Versi konsep ini dibangun dengan stack modern:

- **Frontend:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database ORM:** Drizzle ORM
- **Architecture:** Client-Server model
